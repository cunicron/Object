# Object —— 控制台文字格斗游戏

一个用**纯 Java** 编写、运行在命令行的文字格斗游戏，包含 **账号系统**、**角色养成** 与 **回合制战斗** 三大模块。

无任何第三方依赖，只需要 JDK 21。

> **项目来源**：本仓库为个人学习项目，代码是跟随 B 站「黑马程序员」2026 版 AI + Java 零基础教程

## 功能特性

### 一、账号系统

| 功能 | 规则 |
|---|---|
| 用户注册 | 用户名 3~16 位、只能由字母和数字组成、不能是纯数字、不能重复 |
| 密码设置 | 3~8 位、必须是小写字母 + 数字的组合、不能是纯数字 |
| 用户登录 | 校验用户名是否存在、密码是否匹配 |
| 冻结校验 | 被冻结的账号会提示联系管理员 |
| 验证码 | 登录前需通过随机验证码校验 |

### 二、角色系统

- 角色名与玩家用户名保持一致
- 属性：生命值 `HP` / 最大生命值 `maxHP` / 攻击力 `ATK` / 防御力 `DEF`
- 技能列表：每个角色可携带多个技能（`ArrayList<Skill>`）
- 进入战斗前可分配属性点

### 三、技能系统

- `skillCost` —— 释放技能消耗的生命值
- `skillAT` —— 技能攻击倍率，最终伤害 = `ATK × skillAT`
- 随机回血 —— 部分技能按随机数恢复 0 / 10 / 20 点生命

### 四、战斗系统

四种敌人，各自拥有独立属性与专属技能：

| 敌人 | HP | ATK | DEF | 专属技能 | 伤害倍率 |
|---|---|---|---|---|---|
| 初级战士 | 80 | 15 | 10 | 猛击 | 1.5 |
| 敏捷刺客 | 60 | 20 | 5 | 快速攻击 | 1.5 |
| 重装坦克 | 120 | 10 | 20 | 防御姿态 | 1.0 |
| 神秘法师 | 70 | 25 | 8 | 火球术 | 1.8 |

战斗机制：

- **防御减伤**：攻击伤害会扣除目标的 `DEF` 后结算
- **技能选择**：每回合玩家可选择普通攻击或释放技能
- **数据深拷贝**：`deepCopyList()` 保证每场战斗使用独立的敌人状态，互不污染
- **角色成长**：战斗胜利后角色属性提升（`characterPromove`）

## 如何运行

### 方式一：IntelliJ IDEA（推荐）

1. 打开 IDEA，选择 `File → Open`，选中本项目根目录
2. 若提示没有 SDK：`File → Project Structure → Project`，将 SDK 设为 **JDK 21**
3. 打开 `src/App.java`，点击 `main` 方法左侧的绿色三角运行

> 本仓库已包含 `Object.iml` 与 `.idea/misc.xml`，克隆后 IDEA 能自动识别 `src` 为源码根目录，无需手动配置。

### 方式二：命令行

```bat
cd /d E:\All_Project\java\Object
javac -encoding UTF-8 -d out -sourcepath src src\App.java
java -cp out App
```

**Windows 终端乱码的处理**：程序输出包含中文与 emoji，若显示乱码，请先切换代码页：

```bat
chcp 65001
```

**注意**：程序是**交互式**的，通过 `Scanner` 读取键盘输入，必须在可以手动输入的终端中运行。
若通过管道或重定向喂入输入（例如 `echo 3 | java -cp out App`），会在输入耗尽后抛出
`NoSuchElementException`，这是预期行为，不是缺陷。

## 已知局限与可改进方向

这是一个**学习性质的项目**，为了真实反映当前状态，以下问题被明确记录：

| # | 问题 | 说明 | 改进建议 |
|---|---|---|---|
| 1 | **密码明文存储** | `User.password` 直接保存明文，且注册成功后会原样打印出来 | 改用 `BCrypt` / `Argon2` 加盐哈希；生产环境绝不回显密码 |
| 2 | **无数据持久化** | 用户与角色数据只存在内存中，程序退出即全部丢失 | 引入文件存储（JSON）或数据库（SQLite / MySQL） |
| 3 | **`Login.java` 职责过重** | 739 行同时承担输入校验、流程控制、战斗结算三件事 | 拆分为 `UserService`、`BattleService`、`InputValidator` |
| 4 | **未使用构建工具** | 目前是 IDEA 原生 Java 模块工程，靠 `.iml` 描述结构 | 改造为 Maven / Gradle 项目，源码移至 `src/main/java/` |
| 5 | **无单元测试** | 校验与伤害计算等纯逻辑没有测试覆盖 | 补充 JUnit 5 测试 |
| 6 | **输入健壮性不足** | `Scanner` 未做异常处理，非法输入或 EOF 会中断程序 | 封装安全读取方法，捕获 `InputMismatchException` / `NoSuchElementException` |
| 7 | **魔法数字散落** | 敌人属性、成长数值硬编码在 `charEnemy()` 等方法中 | 抽取到配置文件或常量类 |
